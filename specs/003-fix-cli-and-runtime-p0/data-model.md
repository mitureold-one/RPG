## 1. Entities & Types

### 1.1 Structural Scene Type (`SceneType`)
Canonical enumeration of all 10 structural scene types recognized by `lazy_turn.py`:

```typescript
type SceneType = 
  | "standard"       // Micro-ação em tempo real focada no protagonista
  | "interlude"      // Perspectiva externa cinematográfica (protagonista ausente)
  | "parallel"       // Cena simultânea em outro ponto do mundo
  | "timeskip"       // Montagem literária acelerada (avanço de dias/semanas)
  | "dossier"        // Cena epistolar documental (cartas, relatórios)
  | "flashback"      // Quebra temporal retroativa
  | "prologue"       // Enquadramento de abertura de arco / era
  | "epilogue"       // Rescaldo e fechamento de ciclo após clímax
  | "post_credits"   // Ferrão cinematográfico rápido revelando nova ameaça
  | "fade_to_black"; // Corte poético no limiar de intimidade física
```

### 1.2 Writer Mandate Structure (`step_3_writer_mandate`)
The structured dictionary payload generated by `prepare` and consumed by the writing layer:

```typescript
interface WriterMandate {
  scene_type: SceneType;
  why_this_structure: string;   // Justificativa dramática da estrutura
  structure_and_tone: string;   // Batidas estruturais e tom exigido
  dialogue_and_style: string;   // Regras de travessão, discurso direto e gancho final
}
```

### 1.3 CLI Command Entities

#### `PlanCommand`
```typescript
interface PlanArgs {
  campaign: string;
  list?: boolean;
  add?: string;              // Nova batida dramática / título da cena agendada
  scene_type?: SceneType;    // Tipo estrutural da cena agendada (default: 'interlude')
  actors?: string;           // Personagens específicos em foco
  complete?: number;         // Índice da cena a marcar como concluída
  milestone?: string;        // Novo marco futuro
  json?: boolean;
}
```

#### `ClockCommand`
```typescript
interface ClockArgs {
  campaign: string;
  list?: boolean;
  add?: string;              // Nome da ameaça
  max?: number;              // Segmentos totais (default: 4)
  trigger?: string;          // Condição de ruptura
  advance?: string;          // Nome do relógio
  steps?: number;            // Quantidade de passos a avançar (default: 1)
  resolve?: string;          // Nome do relógio a desarmar
  json?: boolean;
}
```

#### `ArcCommand`
```typescript
interface ArcArgs {
  campaign: string;
  title?: string;            // Novo título do arco
  question?: string;         // Pergunta dramática
  stage?: string;            // Fase (Apresentação, Conflito, Clímax, Resolução)
  scene_name?: string;       // Título da cena inicial
  date?: string;             // Nova data canônica
  location?: string;         // Novo local canônico
  present?: string;          // Personagens presentes
  resolve_clocks?: boolean;  // Marca todos os relógios como resolvidos
  milestone?: string;        // Marco de encerramento do arco anterior
  json?: boolean;
}
```
